# Stellar Dawn Nexus

Static site prototype for the Stellar Dawn campaign hub.

## Pages

- `index.html` - Stellar Dawn Nexus home
- `quiet-ones.html` - The Quiet Ones Quiet Year overview
- `quiet-ones-rules.html` - The Quiet Ones rules and house reference
- `quiet-ones-players.html` - Player-facing guide to role, tone, and expectations
- `quiet-ones-turns.html` - Player-facing turn and action reference
- `characters.html` - Stellar Dawn character roster and relationship hub
- `story.html` - Stellar Dawn story so far, lore, factions, and mysteries
- `rules.html` - Stellar Dawn homebrew rules landing page
- `ships.html` - Stellar Dawn ship information hub
- `shipbuilding.html` - Shipbuilding workflow
- `gear.html` - Gear catalog

## Publishing

This folder is designed to publish directly with GitHub Pages.
