# Stellar Dawn Nexus

Static site prototype for the Stellar Dawn campaign hub.

## Pages

- `index.html` - Nexus home
- `quiet-ones.html` - The Quiet Ones field record
- `ships.html` - Fleet registry starter
- `shipbuilding.html` - Shipbuilding workflow starter
- `gear.html` - Gear catalog starter
- `encounters.html` - GM encounter desk starter

## Publishing

This folder is designed to publish directly with GitHub Pages.
